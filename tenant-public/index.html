1. Connect your model

The setup wizard opens in a new tab. Follow its prompts to choose your model connection, then return here. Keep this page open until setup is complete.

2. Open your dashboard

Copy your connection key, open the dashboard in a new tab, and paste it into the Gateway token field in connection settings. Connect, then return here.

Open dashboard in a new tab

3. Approve this browser

Open the dashboard, then return here and find this browser. Only a device connection observed in your current signed-in session can be approved.

Export your complete agent

Export briefly pauses the agent to capture consistent state. The archive contains memory, sessions, files, configuration, and credentials. It is encrypted to the public key you supplied.
