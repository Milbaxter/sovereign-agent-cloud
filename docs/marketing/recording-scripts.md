# Product recordings

Status: scripts and storyboards, not recordings. Use a disposable demonstration account with fictional preferences and no visible keys or private messages. Record the live agent only after the task works. Do not substitute the website's scripted example and call it a product recording. Disclose cuts and time compression.

## Main demonstration — 75 seconds

**0–8 seconds — The request.** Show a real agent conversation. Voiceover: “A personal agent should help with your day—and leave you in control.” Type: “Help me plan a quiet weekend. I like walks and coffee, and want to keep it under €100.”

**8–28 seconds — A useful result.** Show the actual response and refine it: “Turn that into a simple plan I can adjust.” Voiceover: “Start with something ordinary. Give it your preferences, then shape the result together.” Show actual sources if it researched places or prices. Do not imply it booked anything.

**28–43 seconds — Context.** Start a separate conversation using the product's real UI. Ask: “What about next weekend?” Voiceover: “The context is what makes it personal.” Show only memory the agent actually retained. If it does not retain the preferences, stop: the memory claim is not ready.

**43–55 seconds — Choice.** Show the real supported model selector without credentials. Voiceover: “You choose the supported model provider. Your agent’s hosting and its model are separate choices.” Display the actual processing location disclosure.

**55–67 seconds — Ownership.** Export the demonstration account's real data. Open the downloaded file and point to fields that exist. Voiceover: “And you can export your data. This is data export; full agent migration is the next milestone.”

**67–75 seconds — Offer.** End card: “Your personal AI. On your terms. €25/month + inference and applicable tax. First 50 customers. Base price held for 12 months.” Show the verified public URL.

Export an MP4 with readable captions and an SRT/VTT transcript. Capture a clean 16:9 recording; cut 9:16 versions only when controls and text remain legible. Do not speed through billing disclosures.
